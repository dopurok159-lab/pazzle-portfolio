# Мой учебный репозиторий

Этот репозиторий предназначен для хранения домашних заданий, практических работ и итоговых проектов в рамках обучения программированию.

## Структура репозитория

Репозиторий содержит два учебных курса:

- `course-2` — материалы второго курса.
- `course-3` — материалы третьего курса.

Каждый курс содержит три папки:

- `homeworks/` — домашние задания.
- `practices/` — практические работы.
- `projects/` — итоговые проекты.

## Структура отдельного задания

Каждое задание может содержать:

- `task.md` — описание задания.
- `solution/` — файлы выполненной работы.
- `README.md` — отчёт о выполнении и инструкция по проверке.

## Как проверить задания

1. Откройте папку нужного курса.
2. Перейдите в `homeworks`, `practices` или `projects`.
3. Выберите нужное задание.
4. Прочитайте `task.md`.
5. Ознакомьтесь с решением в `solution/`.
6. Прочитайте `README.md` с результатами выполнения.
