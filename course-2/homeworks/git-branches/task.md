# Домашнее задание: Ветки в Git

## Цель работы

Научиться создавать ветки в Git, переключаться между ними, выполнять слияние и разрешать merge-конфликты.

## Задание 1. Создание репозитория

1. Создать папку `git-branches`.
2. Инициализировать Git-репозиторий.
3. Создать файл `story.txt` с текстом «Это начало моей истории.».
4. Сделать первый коммит.
5. Создать ветку `feature`.

## Задание 2. Работа с веткой feature

1. Переключиться на ветку `feature`.
2. Добавить в `story.txt` строку «Ветка feature добавляет новую главу.».
3. Сохранить изменения и сделать коммит.

## Задание 3. Работа с веткой main

1. Переключиться на ветку `main`.
2. Добавить строку «Ветка main продолжает свою версию истории.».
3. Сделать коммит.

## Задание 4. Слияние веток

1. Находясь в ветке `main`, выполнить `git merge feature`.
2. Получить merge-конфликт в файле `story.txt`.

## Задание 5. Разрешение конфликта

1. Открыть файл `story.txt`.
2. Удалить конфликтные маркеры.
3. Сохранить изменения из обеих веток.
4. Выполнить `git add story.txt`.
5. Завершить слияние командой `git commit`.

## Ожидаемый результат

Файл `story.txt` должен содержать три строки:

```text
Это начало моей истории.
Ветка main продолжает свою версию истории.
Ветка feature добавляет новую главу.
```

История Git должна содержать коммиты обеих веток и итоговый merge-коммит.
