## Описание работы

В данной работе были изучены основные возможности Git для работы с ветками, создания коммитов и разрешения конфликтов при слиянии.

## Что было сделано

1. Создан Git-репозиторий `git-branches`.
2. Создан файл `story.txt`.
3. Создана основная ветка `main`.
4. Создана дополнительная ветка `feature`.
5. В каждой ветке внесены отдельные изменения.
6. Выполнена команда `git merge feature`.
7. Получен merge-конфликт.
8. Конфликт разрешён вручную с сохранением изменений обеих веток.
9. Создан итоговый merge-коммит.

## Структура решения

## Как проверить результат

1. Открыть файл `solution/story.txt`.
2. Убедиться, что файл содержит три строки из задания.
3. Открыть `solution/git-history.txt` и посмотреть граф коммитов.
4. Для проверки настоящих веток открыть отдельный репозиторий `git-branches` и выполнить:

```bash
git branch
git log --oneline --graph --all
git status
```
